## Fix summary
This change fixes the remaining pipe lifecycle bug in the flappybird game.

### Problem
The game only spawned a fixed initial set of pipes and never produced additional ones after that. It also kept old pipes in memory even after they moved off-screen, which could lead to unnecessary objects accumulating and eventually affecting gameplay or performance.

### Root cause
`PipeHandler` only ran a one-time startup spawn and then stopped generating new pipes. There was no periodic spawn logic, and no cleanup step removed pipes that had moved beyond the left edge of the screen.

### Fix
- Added a timed spawn loop so new pipes continue to appear during gameplay.
- Kept a consistent gap between generated pipes to preserve playable spacing.
- Removed any pipe whose right edge has moved past the left side of the screen so the vector does not grow indefinitely.

This keeps the game generating an endless stream of pipes without retaining stale off-screen objects.
